你可能想知道的事

以下问答均为占位内容，正式上线前请逐条替换为真实答案。

支持哪些 iOS 版本？

iOS 11以上版本均可运行。

会消耗大量电量吗？

实测 SE 版本的耗电量较大。

数据会上传吗？隐私如何保证？

占位：PC on iPhone 中，“桥接”模式可能会绕过主机 VPN ；本地处理范围、是否联网、收集哪些诊断信息。

为什么 Safari 上玻璃效果不一样？

本站使用 WebGPU 实现液态玻璃折射效果，Safari 与部分设备暂不支持。 这些浏览器会自动降级为 CSS 毛玻璃材质，内容与功能不受影响。

遇到问题怎么反馈？

可以在 GitHub Issues 提交，请附上机型、系统版本与复现步骤。

没找到答案？

直接去仓库提问，通常一两天内会有回复（占位描述）。
