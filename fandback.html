问题反馈

遇到问题了？告诉我们

在使用 PC on iPhone 的过程中，如果您遇到闪退、卡顿或功能异常，请通过以下方式提交反馈。提交前请先浏览一遍 常见问题。

邮件反馈

如果有报错截图或日志，可以在邮件中作为附件添加。

GitHub 提交 (推荐)

如果您有 GitHub 账号，强烈建议直接在仓库提交 Issue。这样所有的报错日志和讨论都能被完整保留，也方便其他遇到相同问题的用户查阅。

提交 Issue 前建议：

  • • 搜索是否已有相同问题
  • • 附上机型和系统版本
  • • 贴上 Xcode 或 StikDebug 的控制台报错
