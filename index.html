PC on iPhone

作为 UTM 的优化版，PC on iPhone 是一款专为 iOS 打造的高性能虚拟机 (VM) 与系统模拟器。基于 QEMU，让你在 iPhone 和 iPad 上无缝运行 Windows、Linux 等桌面系统。

核心亮点

PC on iPhone 的特色

基于 QEMU

基于 QEMU 全系统模拟（MMU、设备等）。

支持30+处理器架构

包括 x86_64、ARM64 和 RISC-V。

图形模式

使用 SPICE 与 QXL VGA 图形模式。

文本终端模式

使用文本终端模式。

USB 设备直通

USB 设备直通。

JIT 加速

基于 QEMU TCG JIT 加速。

最新 API

采用最新 API，为 iOS 11 以上版本从头设计的前端。

快速管理

直接在设备上新建、管理、移除虚拟机，支持管理缓存。

上手流程

三步开始

从 GitHub 下载

在 GitHub 仓库 Release 页面中下载安装包。

完成安装和信任

使用签名工具签名安装，安装后在设置 > 通用 > VPN与设备管理中信任证书。

开始使用

非 SE 版本需要使用配置工具打开 JIT 加速，完成后方可使用； SE 版直接打开使用即可。
