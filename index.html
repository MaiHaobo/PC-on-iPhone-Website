PC on iPhone

PC on iPhone 作为 UTM 的优化版，适用于 iOS 的全功能系统模拟器与虚拟机宿主。它基于 QEMU，让你在 iPhone 和 iPad 上运行 Windows、Linux 等系统。

核心亮点

PC on iPhone 的特色

基于 QEMU

基于 QEMU 全系统模拟（MMU、设备等）。

支持30+处理器架构

包括 x86_64、ARM64 和 RISC-V。

图形模式

使用 SPICE 与 QXL VGA 图形模式。

文本终端模式

使用文本终端模式。

USB 设备直通

USB 设备直通。

JIT 加速

基于 QEMU TCG JIT 加速。

最新 API

采用最新 API，为 iOS 11 以上版本从头设计的前端。

快速管理

直接在设备上新建、管理、移除虚拟机，支持管理缓存。
