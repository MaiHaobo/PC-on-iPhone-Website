详细安装指南

四步开始你的 虚拟机体验

因为 iOS 的安全限制，安装全功能模拟器需要经过签名与 JIT 配置。请按照下方详细指南逐步操作，遇到问题可随时查看常见问题。

获取安装包

前往我们的 GitHub Releases 页面，根据你的设备状况（是否可以启用 JIT 权限、是否支持 HV 等）下载对应版本的 .ipa 安装包。

前往下载页面 →

使用工具签名

iOS 不允许直接安装未经认证的 IPA。你需要下载第三方工具：

  • • TrollStore：如果您的 iOS 支持（如 iOS 14-16.6.1 等），可直接点击 IPA 文件安装，永久有效，免签神器。
  • • AltStore / SideStore：需要配合电脑或 WireGuard 使用 Apple ID 签名，安装后需每 7 天续签一次。
  • • 证书签名：如果你购买了企业证书，可使用轻松签、全能签等工具直接导入安装。

信任开发者证书

安装完成后，首次点击应用图标通常会弹窗提示“不受信任的开发者”。

请前往手机的：
设置 > 通用 > VPN与设备管理
在“企业级 App”或“开发者 App”列表中，找到对应的证书并点击“信任”，即可返回桌面打开。

配置 JIT 与运行

SE 版：直接打开即可使用。
标准版 / HV 版：为了模拟器性能，必须开启 JIT 加速。你需要使用电脑端的 StikDebug、SideStore，或者在手机上使用特定的快捷指令来引导开启。如果启动时一直黑屏，通常是 JIT 没有成功开启。

进阶提示

关于 JIT 加速与卡顿

由于 iOS 的内存和 CPU 限制，如果不开启 JIT，QEMU 模拟器的性能会大打折扣，甚至无法引导 Windows 系统。建议在安装完成后，务必仔细阅读签名工具提供的 JIT 开启教程。
