安装指南

四步开始你的 PC 体验

因为 iOS 的限制，安装 PC on iPhone 需要一些额外的签名步骤。请按照下方指南选择适合你的工具进行安装。

获取安装包

前往我们的 GitHub Releases 页面，根据你的设备状况下载对应版本的 .ipa 安装包。

去下载页面 →

使用工具签名

你需要使用第三方工具来签名安装：

  • • TrollStore：如果您的 iOS 支持（如 iOS 14-16.6.1 等），可直接安装，永久有效。
  • • AltStore / SideStore：需要配合电脑或 WireGuard 使用 Apple ID 签名（有效期 7 天）。
  • • 其他签名工具：可能需要个人证书或企业证书签名安装。

信任开发者证书

安装完成后，首次打开应用会提示“不受信任的开发者”。
请前往手机的 设置 > 通用 > VPN与设备管理，找到对应的开发者证书并点击“信任”。

配置 JIT 与运行

SE 版：直接打开即可使用。
标准版 / HV 版：需要使用配置工具（如 StikDebug / SideStore）或特定快捷指令来启用 JIT 加速，否则可能无法启动。

进阶提示

关于 JIT 加速与卡顿

由于 iOS 的内存和 CPU 限制，如果不开启 JIT，模拟器的性能会大打折扣，甚至无法启动 Windows 系统。建议在安装完成后，务必查阅相关工具文档开启 JIT。
