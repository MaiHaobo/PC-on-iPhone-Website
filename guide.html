使用指南

开始你的第一台 虚拟机

成功安装应用后，你需要创建虚拟机并加载系统镜像。由于操作环境是 iPhone / iPad ，触控操作会有些不同，请参考以下指南。

1. 新建虚拟机

打开应用后，点击底部 Tab 栏的“新建”。你需要为虚拟机分配内存（RAM）和 CPU 核心数。

对于标准版和 HV 版，建议内存至少 2GB ，CPU 核心数设置 2-4 个以保证流畅。

对于S1版，建议内存不要超过 2GB ，CPU 核心数设置 1 个，以免占用内存过多。

2. 挂载系统镜像

在新建虚拟机界面/虚拟机设置中找到“启动ISO镜像”或“ CD/DVD ”，点击“浏览”，选择你提前下载好的系统镜像（如 Windows 的 .iso 或 Linux 的 .img 文件）。

3. 键鼠模拟操作

屏幕触控：单指滑动是移动鼠标指针，轻点代表左键单击，双指轻点代表右键。

4. 启动与 JIT 加速

点击屏幕上的“播放”按钮启动。如果你使用的是标准版/ HV 版，需要用 StikDebug 等工具注入 JIT。如果卡在启动界面黑屏，请检查 JIT 是否成功开启。

性能优化建议

如何让虚拟机跑得更快？

  • • 关闭 iPhone 的“低电量模式”，它会严重限制 CPU 性能。
  • • 在应用设置中尝试开启“多线程加速”（TCG Multi-threading）。
  • • 尽量选择轻量级系统（如 TinyCore Linux 或 Windows XP 进行测试），运行 Windows 10/11 可能会非常卡顿。
  • • 保持手机电量充足，边充边玩时注意手机散热。
