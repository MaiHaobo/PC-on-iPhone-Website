The PC on iPhone features

What exactly can it do

Leveraging the powerful QEMU foundation, PC on iPhone offers an incredibly rich operating experience and seamless system-level integration.

Input and Interaction

Touch mapping

Touches on the screen are converted into mouse clicks, and gestures like long-pressing or two-finger tapping correspond to different mouse actions.

Custom gestures

You can assign specific functions to gestures like two-finger or three-finger swiping in your preferences (like cursor movement, screen panning), while pinch gestures are used for zooming in and out.

Touch mode

Provides different options like "drag-and-drop cursor" and "touch mode" to suit the operation logic in various scenarios.

External devices

Supports external keyboards, mice, trackpads, Apple Pencils, and game controllers to instantly boost productivity.

clipboard sharing

Once the UTM Guest Tools are installed on the virtual machine, clipboard sharing can be enabled, allowing seamless text synchronization between the host and the virtual machine.

File sharing

VirtFS (9Pfs)：Enable it in the virtual machine settings and mount the folders from the iOS "Files" app to the virtual machine. It works better on Linux, but Windows doesn't support it as well.

SPICE WebDAV：You need to install the SPICE Guest Tools. Accessing shared folders via local ports works better with Windows VMs.

Windows and multitasking

Multi-window and external display

Open a new window：On iPadOS, click the display icon in the toolbar, and you can specify a different virtual monitor for each new window.

External monitor / AirPlay：When connecting to an external monitor or using AirPlay, you can assign the virtual machine's display to the external screen for an extended screen experience.

The limitations of the iPhone

On the iPhone, it mainly supports single-screen mode, but you can temporarily switch between landscape and portrait layouts using rotation lock and split-screen gestures. Multi-window functionality is limited by the iOS system.

The highlights of the iPad

On the iPad, you can use the system's Split View or Slide Over. Run the virtual machine on one side and use Safari or Notes on the other - true multitasking right there.

Running in the background and maintaining status

iOS doesn't allow apps to run in the background indefinitely, so PC on iPhone provides the following switches to help maintain the virtual machine state as much as possible:

  • • Keep the virtual machine running in the background
  • • Automatically saves while running in the background
  • • Automatically saves when memory is low

Files and peripherals

File system

Deep integration with the iOS "Files" app makes it easy to import ISO images, export log files, and configuration files.

Clipboard sharing

Seamlessly syncs with iOS systems - just copy a piece of code in the virtual machine and paste it directly on your iPhone when you switch back.

External monitor

Supports casting to a large screen via Type-C, offering desktop-level operation visibility and ultra-low latency.
