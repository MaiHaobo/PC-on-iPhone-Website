PC on iPhone

As an optimised version of UTM, PC on iPhone is a high-performance virtual machine (VM) and system simulator specially designed for iOS. Based on QEMU, you can seamlessly run Windows, Linux and other desktop systems on iPhone and iPad.

Start To understand the function
Pre-release Requirements: iOS 11 or later. For a better experience, iOS 15 is recommended Installation package: Standard Edition 148 MB / Slow #Edition 236 MB Based on UTM Optimisation
Key highlights

Features of PC on iPhone

Based on QEMU

Full-system emulation based on QEMU (including MMU, devices, etc.).

Supports over 30 processor architectures

Including x86_64, ARM64, and RISC-V.

Graphic mode

Use SPICE with QXL VGA graphics mode.

Text Terminal Mode

Use text terminal mode.

USB device passthrough

USB device passthrough.

JIT acceleration

Accelerated by QEMU TCG JIT.

Latest API

Frontend rebuilt from scratch using the latest APIs for iOS 11 and above.

Quick management

Create, manage, and remove virtual machines directly on the device, with support for managing cache.

Get started

Non-SE versions require using the configuration tool to enable JIT acceleration, which must be done before use; Slow Edition can be used directly out of the box.
